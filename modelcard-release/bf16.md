# GLM-5.2-SIQ-Fruit-bf16 — the CPU-runnable twin

Plain-BF16 export of the same QNOISE-annealed checkpoint as
[GLM-5.2-SIQ-Fruit](https://huggingface.co/malaiwah/GLM-5.2-SIQ-Fruit)
(5.04B params, 0.46B active, GLM-5.2 `glm_moe_dsa` architecture).
The SIQ/Trellis release requires the SparkInfer CUDA kernels; **this one
needs no GPU at all** — plain `transformers`, plain CPU.

Measured on an Intel i7-14700K (20 threads, `torch.set_num_threads(20)`,
bfloat16): **~32 tok/s greedy decode**, 2 s load, ~10 GB RAM. The
top-8-of-256 expert sparsity is what makes a 5B model this quick on CPU.

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

d = "malaiwah/GLM-5.2-SIQ-Fruit-bf16"
tok = AutoTokenizer.from_pretrained(d)
m = AutoModelForCausalLM.from_pretrained(d, dtype=torch.bfloat16).eval()
ids = tok("Once upon a time", return_tensors="pt")
out = m.generate(**ids, max_new_tokens=40, do_sample=False)
print(tok.decode(out[0]))
# ', there was a little girl named Lily. She loved to play outside...'
```

## What the transformers CPU path does and does not exercise

- **Runs**: the full MLA attention, the 256-expert top-8 MoE, the GLM
  tokenizer — real trained weights, coherent output.
- **Ignored at load** (reported UNEXPECTED, harmless): the DSA indexer
  tensors (transformers serves dense attention — the indexer is a
  long-context sparsity mechanism, not a quality component at short
  context) and the MTP draft layer (no speculative path in
  `generate()`); 4.57B of the 5.04B params load.
- For the production serving paths this proxy exists to test (SIQ
  Trellis dequant, sparse MLA, nvfp4/fp8 KV, MTP speculative decoding),
  use the [SIQ release](https://huggingface.co/malaiwah/GLM-5.2-SIQ-Fruit)
  on the b12x/SparkInfer + vLLM stack with a CUDA GPU.

Training, gauntlet results, and provenance: see the
[base card](https://huggingface.co/malaiwah/GLM-5.2-SIQ-Fruit) and
[github.com/malaiwah/proxy-fruit](https://github.com/malaiwah/proxy-fruit).
Exported with `FRUIT_BF16=1` in `export_fruit.py` (experts kept BF16,
no tier bitmap; same RoPE/MTP serving-layout conversions as the SIQ
export).
